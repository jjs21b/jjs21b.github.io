01

Machine Learning · Medical Imaging

Medical Image Reconstruction

Developed a data-consistent cascade U-Net workflow for reconstructing 8x undersampled single-coil knee MRI from the fastMRI dataset. The model iteratively refines zero-filled inputs while preserving measured k-space values.

What the evaluation showedThe best illustrated slice achieved SSIM 0.9533, PSNR 39.97 dB, and NMSE 0.0011. The broader evaluation also included error maps and hard-case analysis rather than relying on one aggregate score.

  • Cascade U-Net

02

Deep Learning · Computer Vision

3D Left-Atrium Segmentation

Built an end-to-end PyTorch pipeline for segmenting the left atrium from 3D cardiac MRI volumes, including NIfTI preprocessing, a compact 3D U-Net, checkpoint selection, and a Streamlit training dashboard.

What the evaluation showedReached approximately 0.877 validation Dice and 0.0845 best validation loss, with close agreement between the predicted and ground-truth masks in the held-out examples.

04

Scientific ML · Atmospheric Data Assimilation

Score Filter vs. LETKF

Designed four observing-system simulation experiments comparing an Ensemble Score Filter, tuned LETKF, and a no-assimilation baseline in the SPEEDY global atmospheric model using shared truth, backgrounds, and observations.

What the evaluation showedAcross 80-member ensembles and 30 assimilation cycles, no method dominated: the score filter led under fully nonlinear arctangent observations, while LETKF was stronger in linear, coupled-wind, and pressure-only settings.

  • Python
  • Fortran
  • SPEEDY
  • NetCDF
  • Slurm
